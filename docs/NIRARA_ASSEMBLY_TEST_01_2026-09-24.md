# NIRARA — ASSEMBLY TEST 01

**Branch:** `visual/assembly-test-01-real-fragments-20260924`  
**Status:** ACTIVE / NOT CANON  
**Method:** real public-domain / CC0 fragments assembled in browser

## Rule

This test does not generate a scene with AI.

It loads real source images directly from their original public-domain / CC0 hosts and crops, scales, masks, overlaps, recolours and blends them into one still composition.

## Source material used

- China doll heads, Fairbanks Museum / Wikimedia Commons — CC0
- Jean-Baptiste Carpeaux, *Boy crying*, The Met — Public Domain / Open Access
- ClothPack02 — Wikimedia Commons — Public Domain
- Cloth texture — Wikimedia Commons — Public Domain
- Roofless Ruins backplate — Poly Haven — CC0
- Cracked Concrete — Poly Haven — CC0
- Gray Gravel Rock Texture — Wikimedia Commons — CC0
- Cracked color surface — Wikimedia Commons — Public Domain
- Handyman drip-art wall painting — Wikimedia Commons — CC0

## Fragment count

Approx. 15 visible fragments:
- 5 witness crops from one real doll photograph
- 4 dark structural fragments
- 4 central material fragments
- 1 crying-body fragment
- multiple colour / paint contaminations

## Evaluation

Reject the test if it reads as:
- a clean web composition;
- a stock-image collage;
- a horror poster;
- separate cut-outs;
- a scene whose materials do not bind.

Accept only if the still begins to feel like one materially believable, emotionally charged field.
