# NIRARA — REAL ASSET BANK

**Date:** 2026-09-24  
**Status:** ACTIVE RESEARCH BANK  
**Rule:** Build the image from real fragments before adding generative synthesis.

---

# 1. PURPOSE

NIRARA must not be generated as one complete AI scene.

The visual field will be assembled from many real source fragments:
- archival objects;
- sculpture;
- photographed ruins;
- concrete;
- fabric;
- paint;
- static / video noise;
- reflective surfaces;
- self-shot material;
- public-domain and CC0 texture sources.

AI may later assist with edge integration, restoration, masking or transitional synthesis.

AI is **not** the source of the world.

---

# 2. TARGET BANK SIZE

Before Visual Slice 02 is composed, target:

- 12–20 witness / head / eye fragments
- 8–12 structural dark-form fragments
- 10–15 material / surface fragments
- 3–6 central-gap candidate fragments
- 2–4 crying-body / expression fragments
- 3–6 analog noise / optical disturbance fragments
- 6–10 colour / light contamination fragments

Expected total:
**40–60 useful fragments**

Not every collected asset must appear in the final image.

# 4. ASSET CLASSES TO COLLECT NEXT

## WITNESSES
Seek:
- antique doll heads;
- damaged plaster heads;
- ceramic heads;
- masks;
- mannequins;
- puppet heads;
- sculptural eye fragments;
- real photographed eyes only when materially useful.

Avoid:
- generic AI creepy dolls;
- horror-stock imagery;
- polished 3D character packs;
- uniform mascot faces.

## DARK STRUCTURES
Seek:
- apertures;
- burnt doorways;
- deep shelving;
- damaged walls;
- black fabric partitions;
- interior cavities;
- hard shadow planes;
- boxes only when they feel physically real.

## MATERIAL
Seek:
- cracked plaster;
- scorched paint;
- dust;
- oxidised metal;
- stained cloth;
- torn textile;
- wet black surfaces;
- old paper;
- pigment buildup;
- paint runs;
- rubbed charcoal;
- glass reflections.

## UNNAMED CENTRE
The centre should be assembled from several unrelated-but-compatible real fragments.

Candidate recipe:
- rubble edge;
- folded cloth;
- concrete cavity;
- deep shadow;
- one reflective / wet surface;
- one soft ambiguous surface.

The final form should destroy the certainty of each source.

## CRY
Seek:
- sculptural mouths;
- compressed torsos;
- hands;
- small bodies;
- crying or open-mouth studies;
- distorted plaster figures.

The final crying being must remain small and isolated.

## COLOUR / LIGHT
Seek real:
- stained walls;
- reflected sodium light;
- blue fluorescent spill;
- rust-red pigment;
- dirty cream;
- bruised violet;
- green-grey oxidation;
- photographed paint or ink.

Do not add colour merely through generic gradients.

---

# 5. COMPOSITION RULE

Visual Slice 02 must begin as a still composite.

Before animation:
- crop;
- mask;
- scale;
- overlap;
- erase;
- stain;
- colour-contaminate;
- blur selectively;
- preserve hard edges selectively;
- destroy source boundaries.

The result must no longer look like a collection of stock cut-outs.

It should look like one impossible but materially believable field.

---

# 6. PROVENANCE RULE

For every candidate fragment record:
- source;
- original URL;
- creator / institution when known;
- license;
- intended role;
- whether actually used in final work.

Prefer:
1. self-shot material;
2. public domain;
3. CC0;
4. compatible Creative Commons with attribution.

Do not build final public artwork from unlicensed random web images.
